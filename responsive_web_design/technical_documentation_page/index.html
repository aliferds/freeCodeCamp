Introduction

JavaScript (JS) é uma linguagem de programação leve, versátil e orientada a objetos, usada principalmente para dar vida e interatividade a páginas web.

Ela roda dentro de um ambiente (como o seu navegador) e interage com os elementos dele. O JS já vem com ferramentas prontas (como as funções de Array, Date e Math) e pode ser usado em duas frentes:

  • Client-side (Frontend): Roda no navegador do usuário, controlando o HTML e respondendo a ações como cliques de mouse e digitação.
  • Server-side (Backend): Roda no servidor, permitindo que a aplicação converse com bancos de dados e manipule arquivos.
Pre-requisitos

Antes de começar, é recomendável que você conheça o básico de:

  • Como funciona a Internet e a Web.
  • Linguagem de marcação HTML.
  • Lógica de programação (se for iniciante do zero, procure um tutorial básico de lógica primeiro).
JavaScript vs Java

Apesar do nome parecido, JavaScript e Java são linguagens totalmente diferentes.

O JS apenas herdou algumas regras de escrita e estruturas de controle do Java (o que motivou a mudança de nome de LiveScript para JavaScript na época). Porém, enquanto o Java é uma linguagem rígida e fortemente tipada, o JavaScript é livre, flexível e baseado em protótipos (onde os objetos herdam características diretamente de outros objetos de forma dinâmica).

Hello World

Para testar seu primeiro código em JavaScript, execute a função abaixo:

function greetMe(yourName) {
    alert("Hello " + yourName);
}

greetMe("World");
Variaveis

Variáveis são "caixas" usadas para guardar dados no seu programa. Os nomes que damos a elas (identificadores) têm regras:

  • Devem começar com uma letra, sublinhado (_) ou cifrão ($).
  • Podem conter números, mas nunca começar com eles.
  • São case-sensitive (diferenciam maiúsculas de minúsculas). MinhaVariavel e minhavariavel são duas coisas diferentes.
Declarando Variaveis

Você pode criar uma variável de três formas:

1. Com a palavra-chave var (escopo global ou de função):

var x = 42;

2. Apenas atribuindo um valor (cria uma variável global oculta). Evite usar este método.

x = 42;

3. Com a palavra-chave let (forma moderna, com escopo de bloco):

let y = 13;
Escopo de Variaveis

O escopo define onde sua variável existe e pode ser usada:

  • Global: Declarada fora de qualquer função. Pode ser acessada por qualquer parte do código.
  • Local: Declarada dentro de uma função. Só existe lá dentro.

Variáveis criadas com let respeitam blocos (como o if ou while), enquanto var não:

if (true) {
    let bloco = "secreto";
}
console.log(bloco); // Erro! 'bloco' não existe aqui fora.
Variaveis Globais

No navegador, todas as variáveis globais viram propriedades do objeto window. Isso significa que você pode acessá-las usando window.minhaVariavel.

Constantes

Você pode criar um valor que não pode ser alterado usando const. Elas seguem as mesmas regras de escopo do let, mas não aceitam reatribuição e precisam de um valor inicial obrigatório.

const PI = 3.14;

Atenção: Se a constante for um objeto, você ainda pode alterar as propriedades de dentro dele, só não pode substituir o objeto inteiro.

const MEU_OBJETO = {"chave": "valor"};
MEU_OBJETO.chave = "outroValor"; // Permitido!
Tipos de Dados

O JavaScript possui 7 tipos básicos de dados:

  • Primitivos: Boolean (true/false), null (vazio voluntário), undefined (não definido), Number (números), String (textos) e Symbol (identificador único).
  • Object: Estruturas complexas que guardam coleções de dados.
Estrutura If...Else

Usa-se o if para rodar um código caso uma condição seja verdadeira, e o else caso seja falsa:

if (idade >= 18) {
    status = "Maior de idade";
} else {
    status = "Menor de idade";
}

Dica didática: Use sempre chaves {} para envolver as ações, evitando erros de leitura.

Estrutura While

O laço while repete um bloco de código enquanto a condição definida for verdadeira:

var n = 0;
while (n < 3) {
    n++;
}
// O loop roda 3 vezes e para quando 'n' vira 3.
Functions

Funções são blocos de código reaproveitáveis. Para criá-las, definimos o nome, os parâmetros (dados de entrada) e o bloco de execução:

function quadrado(numero) {
    return numero * numero; // Retorna o resultado
}

Valores primitivos (como números) são passados para as funções por valor. Ou seja, mudar o número dentro da função não altera a variável original do lado de fora.
